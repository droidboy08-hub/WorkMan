Design language and key screens for the habit, money and pay tracker. The Today screen works: try Start break and Punch out. Type a new pay rate on the setup screen and the Today screen uses it.

App theme

Design language: Time Card

Based on the paper time card and the punch clock at work. Clean iPhone-style layout. All times and money use a typewriter-style number font, so digits line up like a stamped card. Key cards have punched notches on the sides. Only three colors carry meaning, so the user learns them fast.

Rules

  • Green only means money coming in. Coral only means money going out.
  • One main button per screen, in ink.
  • Times and money always in the mono font.
  • Cards have 18px corners. Buttons are full pills.
  • Every color has a light and a dark version. Use the theme switch above.
